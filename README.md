# Maching-Learning-Project

ME4452 project: train a neural network to predict wing lift and drag coefficients
from data generated by a nonlinear, polar-corrected vortex-lattice solver using
AeroSandbox and NeuralFoil.

In `notebooks/data_generation.ipynb`, set the numeric ranges in `doe_bounds`
and the named airfoil choices in `airfoils`:

| Input | Meaning / units |
| --- | --- |
| `aspect_ratio` | Full-wing aspect ratio |
| `area_m2` | Full-wing planform area, m² |
| `taper_ratio` | Tip chord / root chord |
| `tip_twist_deg` | Tip twist relative to the root, degrees |
| `alpha_deg` | Angle of attack, degrees |
| `velocity` | Freestream velocity, m/s |
| `airfoil` | Symmetric airfoil name, such as `naca0012` or `naca0015` |

Bounds use `(minimum, maximum)`; equal bounds keep an input fixed. Set `n_samples`
and `seed` to control the Latin hypercube sample count and reproducibility.
The notebook previews all seven inputs, then solves cases in CPU worker processes.
Set `n_jobs` to `-2` for all CPUs except one, `-1` for all CPUs, `1` for serial
execution, or a positive worker count. Workers are capped at the number of cases,
with one numerical-library thread each. The notebook saves results to
`data/wing_data_trial.csv` in DOE order as results are received.
A new run replaces the previous CSV after the first successful case.

Root twist and sweep are fixed at zero. Twist varies linearly to the tip;
negative `tip_twist_deg` means washout. The solver retains its approximate
effective-incidence coupling and requires symmetric airfoils.

The current bounds use 2 to 6 degrees angle of attack, 40 to 100 m/s velocity,
and taper ratios from 0.2 to 0.5. These choices help the small-angle coupling
converge and avoid nearly zero tip chords. They passed a 500-case screening
at reduced resolution and 16 selected cases at the full 40-by-4 resolution.

Reynolds number is derived from `Re = velocity * chord / kinematic_viscosity`
using the default atmosphere, rather than supplied as an input. The solver uses
local chord at each station; the CSV's derived `reynolds` column uses mean
aerodynamic chord. See [NASA's Reynolds number definition](https://www.grc.nasa.gov/WWW/K-12/airplane/reynolds.html).

The outputs are `CL` and `CD_profile`, with convergence/runtime diagnostics.
`notebooks/train_surrogate.ipynb` uses all seven inputs, encodes airfoil names
as numeric indicator columns, and holds out sampled cases for testing.
Regenerate the CSV before training so it contains the current input columns.

Install solver dependencies with `python -m pip install -e ".[solver]"`; data
generation also needs pandas and matplotlib. Training dependencies are installed
with `python -m pip install -e ".[surrogate]"`. Both notebooks can run from the
project root or the notebooks directory.

The plotting section shows lift versus angle of attack, profile drag versus
angle of attack, and lift versus profile drag, with points colored by aspect ratio.
