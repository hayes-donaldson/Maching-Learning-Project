# Maching-Learning-Project

ME4452 project: train a neural network to predict wing lift and drag coefficients
from data generated by a nonlinear, polar-corrected vortex-lattice solver using
AeroSandbox and NeuralFoil.

This repository provides an experimental nonlinear section-polar corrected VLM,
NeuralFoil polar caching/interpolation, analytic trapezoidal geometry, and
geometry-grouped splitting. Dataset generation, preprocessing pipelines, model
training and evaluation remain TODO and raise `NotImplementedError`. No production
dataset or trained model has been generated. Numerical convergence does not
establish aerodynamic accuracy; the correction method still needs validation.

## Setup

Use Python 3.10 or newer with an interpreter supported by the selected scientific
dependencies. The solver extra pins AeroSandbox 4.2.10 and NeuralFoil 0.3.3,
the versions checked for this implementation. Record the complete environment
before generating project datasets. Core package imports require no aerodynamic
or ML libraries; numerical tests require the solver extra.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
python -c "import solver, wing_surrogate; print(solver.__file__); print(wing_surrogate.__file__)"
```

Install optional dependencies for the intended workflows:

```powershell
python -m pip install -e ".[solver,surrogate,dev]"
python -m pytest
```

On macOS/Linux use `python3 -m venv .venv` and `source .venv/bin/activate`.
Both packages are discovered from `src/` by setuptools. Scripts use installed
packages, so no manual `sys.path` changes or `PYTHONPATH` settings are needed.

## Solver interpretation and remaining implementation

[Model assumptions](docs/model_assumptions.md) describes the implemented
experimental boundary correction and its limitations. AeroSandbox supplies the
chordwise mesh and horseshoe kernels. The custom iteration changes vortex
strengths to match NeuralFoil section CL at effective section angles. It keeps
multiple chordwise panels and does not substitute nonlinear lifting-line.
Section CD adds profile drag to the VLM near-field induced drag. Swept-wing
section treatment is approximate, beta must be zero, and freestream Mach must
be below 0.3. All settings and domain cutoffs remain provisional.

After installing the solver extra, run this in your notebook. Use the project
environment as the kernel and restart it after editable installation or changes
to imported modules.

```python
from pathlib import Path
from solver import (
    WingParameters, build_wing_geometry,
    OperatingPoint, SolverSettings, run_solver,
)

# Resolve the root whether the notebook starts in notebooks/ or the repository.
root = Path.cwd()
if not (root / "pyproject.toml").exists():
    root = root.parent
assert (root / "pyproject.toml").exists(), "Start in the repository or notebooks folder"

wing = build_wing_geometry(WingParameters(8.0, 1.0, 0.5, 0.0, "naca0012"))
conditions = OperatingPoint(
    alpha_deg=5.0, velocity_m_s=20.0, density_kg_m3=1.225,
    dynamic_viscosity_pa_s=1.789e-5, speed_of_sound_m_s=340.0,
)
result = run_solver(wing, conditions, SolverSettings(), root / "data/raw/polar_cache")
print(result)
if result.converged:
    print(f"CL={result.cl:.6f}, CD={result.cd:.6f}")
    print(f"Induced CD={result.cd_induced:.6f}, profile CD={result.cd_profile:.6f}")
else:
    print(result.status, result.error_message)
```

`run_solver` reports converged, unconverged, or failed status and elapsed wall
time including polar-cache work. Failed/unconverged cases have null CL/CD.
Missing optional dependencies raise an import error instead of recording a
physical case failure. Polar queries outside the angle table or below the
confidence threshold are rejected, with the reason in the result.
